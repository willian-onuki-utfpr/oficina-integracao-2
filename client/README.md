# Oficina Web - Frontend

Sistema frontend desenvolvido com React, TypeScript e Vite para gerenciamento de oficinas, professores, tutores, alunos e certificados.

## Pré-requisitos

Antes de iniciar, certifique-se de possuir as seguintes versões instaladas:

### Node.js

```bash
node -v
```

Versão recomendada:

```text
v20.19.0
```

### NPM

```bash
npm -v
```

Versão recomendada:

```text
10.8.x ou superior
```
